# Rexy Kurniawan - Personal Portfolio Website

Website portofolio pribadi profesional yang dibuat menggunakan HTML, CSS Bootstrap, dan JavaScript. Website ini menampilkan profil, pengalaman, skills, project portfolio, serta informasi kontak.

## Preview

Website ini berisi beberapa section utama:

- Home
- About Me
- Skills
- Projects
- Contact
- Footer

## Tech Stack

Project ini dibuat menggunakan:

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons
- GitHub Pages

## Features

- Responsive design untuk desktop, tablet, dan mobile
- Sticky navbar
- Smooth scrolling
- Dark mode toggle
- Typing animation pada hero section
- Reveal animation saat scroll
- Project filtering berdasarkan kategori
- Contact card yang dapat diklik
- Floating WhatsApp button
- Back to top button
- Background modern dengan gradient dan glassmorphism effect
